# Unidad 1 - Primer Parcial

Bienvenido al repositorio de Matías Pico. Aquí se agrupan los trabajos, deberes, actividades prácticas y evaluaciones correspondientes a la **Unidad 1 y 2** del primer parcial académico.

---

## 📁 Estructura del Repositorio

El proyecto está organizado en las siguientes carpetas y contenidos:

- **`APE/`**: Trabajos prácticos y de aprendizaje práctico-experimental.
- **`Cafeteria_Universitaria/`**: Proyecto o caso de estudio práctico desarrollado en clase.
- **`DEBERES/`**: Tareas, ejecuciones individuales y ejercicios asignados para la casa.
- **`EJERCICIOS EN CLASE/`**: Algoritmos, guías y actividades desarrolladas activamente durante las sesiones de clase.
- **`prueba-practica-logica-Matias-Pico/`**: Evaluación o prueba práctica de lógica de programación realizada por **Matías Pico**.
